Credit Card Fraud Rate Visualization

A beginner-friendly Python data visualization project that explores credit card fraud rate trends across different years using sample data.

Project Overview

This project uses Python libraries to read a CSV dataset and visualize yearly fraud rates through a bar chart.

Technologies Used

- Python
- Pandas – Data handling
- Matplotlib – Data visualization

Project Structure

first-aiml-project/
│
├── fraud_analysis.py
├── dvp.csv
└── README.md

How to Run

1. Clone or download this repository.
2. Install the required libraries:

pip install pandas matplotlib

3. Run the Python file:

python fraud_analysis.py

Dataset

The "dvp.csv" file contains illustrative sample data with two columns:

- Year
- Fraud Rate (per $100 spent)

Note: The dataset contains sample values for learning and demonstration purposes, not verified real-world statistics.

Learning Outcomes

- Reading CSV files using Pandas.
- Extracting and handling dataset columns.
- Creating bar charts using Matplotlib.
- Understanding basic data visualization.
